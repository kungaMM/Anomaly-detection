# Anomaly-detection
Обнаружение аномалий в данных промышленного мониторинга
Репозиторий магистерской выпускной квалификационной работы на тему «Разработка и исследование методов обнаружения аномалий в многомерных данных промышленного мониторинга».
Статус проекта: исследовательский проект в разработке. Разделы об экспериментах и результатах будут дополняться по мере реализации. Указание метода в плане не означает, что он уже реализован или проверен.

Цель работы
Исследовать и сравнить статистические методы, алгоритмы классического машинного обучения и нейросетевые модели обнаружения аномалий в многомерных данных промышленного мониторинга на примере гидравлической и пневматической систем.
Датасеты
В работе планируется использовать два набора данных.
1. Hydraulic Systems
- Источник: UCI Machine Learning Repository — Condition monitoring of hydraulic systems
- Описание: данные лабораторного гидравлического стенда, содержащие измерения различных параметров системы и сведения о состоянии отдельных компонентов.
- Планируемая роль: основной набор данных для разработки и сравнения методов.
Перед экспериментами необходимо проверить формат файлов, частоты дискретизации, схему признаков и правила формирования целевой разметки. Состояние компонента не следует автоматически приравнивать к аномальности каждого отдельного измерения.
2. MetroPT-3
- Источник: UCI Machine Learning Repository — MetroPT-3 Dataset
- Описание: временные ряды параметров работы пневматической системы поезда метро, включая измерения компрессора.
- Планируемая роль: проверка применимости методов на эксплуатационных данных другого типа.
В наборе документированы интервалы отказов, но это не равнозначно точной метке аномальности для каждой строки. Это ограничение необходимо учитывать при подготовке эксперимента и интерпретации метрик.

Датасеты будут анализироваться отдельно: у них различаются структура, измеряемые величины и особенности разметки. Объединять исходные таблицы в одну общую выборку не планируется.
Планируемые методы
В качестве отправной точки рассматриваются следующие методы:
- Расстояние Махаланобиса — статистический базовый метод.
- Isolation Forest — метод обнаружения выбросов на основе изоляции наблюдений.
- Autoencoder (AE) — нейросетевая модель, использующая ошибку реконструкции как оценку аномальности.
- LSTM Autoencoder (LSTM-AE) — модель реконструкции временных последовательностей.
Окончательный перечень методов может быть уточнён после первичного анализа данных и оценки вычислительных затрат.
План экспериментов
1. Изучить структуру исходных данных и документацию датасетов.
2. Проверить пропуски, типы данных, временные метки и частоты измерений.
3. Подготовить признаки или временные окна с учётом структуры каждого набора.
4. Разделить данные на обучающую, калибровочную и тестовую части с учётом временного порядка, где это применимо.
5. Обучать модели преимущественно на данных нормальной работы, если это соответствует выбранной постановке.
6. Настроить пороги обнаружения без использования тестовых меток.
7. Сравнить качество и вычислительные затраты методов.
Для временных данных важно предотвращать утечку информации между обучением и тестированием. Нормализация и другие преобразования должны подгоняться только на обучающей части.
Метрики оценки
Планируется рассмотреть:
- Precision — точность обнаружения положительного класса;
- Recall — полнота обнаружения;
- F1-score — гармоническое среднее Precision и Recall;
- PR-AUC — площадь под кривой Precision–Recall;
- False Positive Rate (FPR) — доля ложноположительных срабатываний;
- Время выполнения — вычислительные затраты метода.
Для MetroPT-3 дополнительно может оцениваться доля обнаруженных зарегистрированных интервалов отказов и задержка обнаружения. Метрики и правила сопоставления предсказаний с интервалами будут описаны после уточнения протокола оценки.
