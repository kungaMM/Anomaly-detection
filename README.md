# Разработка и исследование методов обнаружения аномалий в многомерных данных промышленного мониторинга

Репозиторий магистерской выпускной квалификационной работы на тему **«Разработка и исследование методов обнаружения аномалий в многомерных данных промышленного мониторинга»**.

## Описание проекта

Проект посвящён исследованию методов обнаружения аномалий в многомерных данных промышленного мониторинга. Рассматриваются статистические методы, алгоритмы классического машинного обучения и нейросетевые модели, позволяющие выявлять отклонения в показаниях датчиков.

В работе планируется исследовать данные двух промышленных систем: гидравлического стенда Hydraulic Systems и пневматической системы поезда метро MetroPT-3.

## Цель работы

Исследовать и сравнить статистические методы, алгоритмы классического машинного обучения и нейросетевые модели обнаружения аномалий в многомерных данных промышленного мониторинга на примере гидравлической и пневматической систем.

## Датасеты

### 1. Hydraulic Systems

**Источник:** [UCI Machine Learning Repository — Condition monitoring of hydraulic systems](https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems)

Набор данных содержит измерения, полученные при мониторинге лабораторного гидравлического стенда. Данные включают сигналы различных датчиков, характеризующих работу системы, а также информацию о состоянии отдельных компонентов.

**Планируемое использование:**
- исследование структуры многомерных данных;
- предварительная обработка сигналов и формирование признаков;
- разработка и оценка методов обнаружения аномалий;
- анализ результатов с учётом доступной информации о состоянии компонентов.

### 2. MetroPT-3

**Источник:** [UCI Machine Learning Repository — MetroPT-3 Dataset](https://archive.ics.uci.edu/dataset/791/metropt+3+dataset)

Набор данных содержит временные ряды параметров работы пневматической системы поезда метро, включая данные о функционировании компрессора. В описании набора представлены интервалы зарегистрированных отказов.

**Планируемое использование:**
- исследование временных рядов промышленного оборудования;
- подготовка данных для методов обнаружения аномалий;
- оценка применимости разработанных методов на эксплуатационных данных;
- анализ обнаружения зарегистрированных интервалов отказов.

Датасеты будут обрабатываться и оцениваться отдельно, поскольку различаются структура данных, измеряемые параметры и особенности разметки.

## Исследуемые методы

В качестве основных кандидатов для сравнения рассматриваются:

- **Расстояние Махаланобиса** — статистический метод обнаружения отклонений с учётом взаимосвязей между признаками.
- **Isolation Forest** — алгоритм классического машинного обучения для обнаружения аномальных наблюдений.
- **Autoencoder (AE)** — нейросетевая модель, использующая ошибку реконструкции данных в качестве оценки аномальности.
- **LSTM Autoencoder (LSTM-AE)** — модель реконструкции последовательностей, учитывающая временную структуру данных.

Окончательный перечень методов будет уточнён после анализа данных и оценки вычислительных затрат.
